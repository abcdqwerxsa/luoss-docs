## 存储概览

| 信息 | 说明 |

### 存储类型

平台提供三层存储，**请按下列优先级使用**：

| 优先级 | 存储类型 | 容器内路径 | 适用场景 | 持久性 |
|--------|----------|-----------|----------|--------|
| 🥇 **优先** | 共享文件存储 | `/mnt/host-model` | 数据集、模型、项目代码等**大文件**（约 500 T 共享分布式文件存储） | 持久，跨开发环境/训练任务共享 |
| 🥈 **其次** | 开发环境持久存储（工作盘） | 容器内 `/`（OverlayFS 根） | 安装系统工具（pip / apt）、conda 环境、配置等 | 持久，环境重启保留；删除环境仅解绑、数据保留 |
| 🥉 **不推荐** | 临时存储（ephemeral） | `docker run` 容器内、`/tmp` 等 | 仅作临时计算中间产物 | **容器/环境重建后自动释放，切勿存放重要数据** |

::: tip 路径对照
开发环境**容器内**的共享文件存储挂载在 `/mnt/host-model`，对应**宿主机（以及调试节点裸机 SSH）**的 `/mnt/model`——是同一份约 500 T 的共享存储，只是两个视角下的路径不同。
:::

### 存储路径

用户存储挂载到开发环境和训练任务：

| 环境 | 挂载路径 | 说明 |
|------|----------|------|
| 开发环境 - 共享文件存储 | `/mnt/host-model` | 约 500 T 共享分布式存储，跨环境/任务共享（推荐存大文件） |
| 开发环境 - workspace | `/config/workspace` | 共享 PVC，适合配置、脚本等轻量数据 |
| 开发环境 - 工作盘 | 容器根文件系统 `/` | Longhorn PVC 全量持久化（pip/apt install 等均保留，容量自选） |
| 训练任务 | `/models` | 训练数据与输出 |

::: tip 共享存储
开发环境通过 `/mnt/host-model` 共享同一份约 500 T 的分布式文件存储，数据在不同环境、训练任务间互通，适合存放代码、数据集和模型文件。`/config/workspace` 为轻量共享 PVC，适合配置/脚本。
:::

::: info 工作盘（Overlay 持久化）
开发环境以一块 Longhorn PVC（即[数据盘](/guide/data-volumes)，挂载在容器内 `/mnt/persistent`）作为 OverlayFS 的可写层，实现全量持久化：容器内的所有修改（安装的包、系统配置等）都写到工作盘上。环境重启后所有修改保留；**删除环境时仅解绑工作盘，数据保留**。详见 [开发环境 - 数据持久化](/guide/environments#数据持久化)。
:::

## 目录结构

推荐的目录结构：

```
/mnt/host-model/         # 大容量共享存储（约 500T，推荐优先存放项目文件）
├── datasets/            # 数据集
│   ├── train/           # 训练数据
│   └── val/             # 验证数据
├── models/              # 预训练模型
│   └── llama-3-8b/
├── output/              # 训练输出
│   └── exp-001/
└── projects/            # 项目代码

/config/workspace/       # 开发环境共享 PVC（适合存放配置文件等轻量数据）
├── configs/             # 配置文件
└── scripts/             # 脚本文件

/ (overlay 根文件系统)    # 全量持久化（工作盘，容量自选）
├── usr/local/lib/       # pip 安装的包（持久化）
├── usr/bin/             # 系统工具（持久化）
└── etc/                 # 系统配置（持久化）
```

::: warning 项目文件优先存储到 /mnt/host-model
**项目文件（包括代码、数据集、模型等）请优先存储到 `/mnt/host-model` 目录下。** 该目录为约 500 T 的大容量共享存储，能够满足大规模数据存储需求。`/config/workspace` 存储空间有限，建议仅用于存放配置文件等轻量数据。
:::

## 使用建议

1. **大文件优先存 `/mnt/host-model`**：约 500 T 共享存储，优先用于存放项目代码、数据集和模型文件，跨环境/任务共享
2. **系统工具装到工作盘**：pip / apt、conda 环境等装在开发环境里（OverlayFS 全量持久化），环境重启不丢失；不要把大文件堆在工作盘，会占用 2 TiB 数据盘配额且无法跨环境共享
3. **`docker run` 容器只用临时存储**：开发环境里通过 DinD 用 `docker run` 启动的容器，其写入的数据落在**临时存储**（ephemeral），容器/环境重建后自动释放——**不要在这里存放任何需要保留的数据**，重要数据写到 `/mnt/host-model`
4. **轻量配置放 workspace**：`/config/workspace` 适合存放配置文件、脚本等轻量数据
5. **定期清理**：删除不需要的文件；工作盘容量按需选择，计入[数据盘 2 TiB 配额](/guide/data-volumes#创建数据盘)
6. **备份重要数据**：定期下载备份关键数据

::: info 上传大小限制
通过页面上传**镜像压缩包 / 模型文件压缩包**，单文件最大 **100 GB**（支持 `.tar` / `.tar.gz` / `.tgz` / `.zip`，镜像上传支持断点续传）。超过 100 GB 的大文件建议先拆分，或通过调试节点 SCP / 共享存储直接放入。
:::

## 常见问题

### Q: 存储空间不足？

A: 清理不需要的文件。overlay 存储可在环境内通过 `du -sh /*` 查看各目录占用。共享 PVC 存储可联系管理员增加配额。

### Q: 如何在不同环境间共享文件？

A: 所有环境共享同一 `/config/workspace` 存储，直接访问对应路径即可。

### Q: pip install 的包在环境重启后还在吗？

A: 在的。开发环境采用全量持久化，容器根文件系统的所有修改（包括 pip/apt 安装）都会保留。

### Q: 工作盘实际占用多少空间？

A: 工作盘是一块 Longhorn PVC（[数据盘](/guide/data-volumes)），容量在创建开发环境时自选（默认 200 GiB）。可在环境内通过 `df -h /`（SSH 视图）查看占用，或在「数据盘」页面查看用量。工作盘支持在线扩容。
